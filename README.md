# Nova AI

Eine moderne KI-Weboberfläche mit:
- Textchat
- Sprachaufnahme und Sprachausgabe
- animiertem Partikel-Orb
- KI-Websuche
- YouTube-Suche und YouTube-Bereich
- vollständiger YouTube-Seite über den offiziellen Button
- Webseiten-Ansicht
- Bildsuche
- Bildgenerierung

## Start

1. Node.js installieren.
2. Dieses Projekt auf GitHub laden.
3. Im Projektordner:
   npm install
4. `.env.example` zu `.env` kopieren.
5. Deinen API-Key in `.env` eintragen.
6. Falls dein API-Anbieter einen anderen Modellnamen verwendet, `OPENAI_MODEL` entsprechend ändern.
7. Starten:
   npm start
8. Im Browser `http://localhost:3000` öffnen.

Wichtig: `.env` niemals auf GitHub hochladen.
